# Help

*Draft (2026-11-03).*

How the game teaches itself:
- **The Bell** teaches the first systems one step at a time: talking and the journal, the bank, potions
  and shops, walking out, the first fight. Tolling's people each introduce one thing.
- **The Guide** lists every skill's unlocks in level order, gathered from the game's own content, so it is
  never out of date.
- **Tooltips** on every item, ability, hymn and status.
- **Messages** say why something can't be done ("Pike requires level 25 Fishing to hook").
- **Pennick** explains death the first time.
