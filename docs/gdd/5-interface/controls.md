# Controls

*Draft (2026-11-03). From `docs/interface.md`, `docs/systems.md` and `docs/fishing.md`.*

| To... | Do |
| --- | --- |
| Walk | click the ground or the minimap |
| The obvious action | left-click a person, creature or object |
| Every action | right-click |
| Use an item on something | Use, then click the target; Escape or walking puts it down |
| Fire an ability, hymn or item | its slot on the main bar: 1 to 0, - and = |
| Answer in a conversation | the number keys; space to go on |
| Chat | Enter |
| Journal, guide, world map, Religion | J, G, M, F |
| Close a modal | Escape |
| Fight a trophy fish | hold Space to reel; move the cursor against the fish (steer controls) |
