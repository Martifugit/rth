# Options that change play

*Draft (2026-11-03). From `docs/systems.md`, `docs/skills.md` 3.2 and `docs/fishing.md`.*

| Option | Choices | What it changes |
| --- | --- | --- |
| **Train defence** | offence, balanced (default), defence | how combat experience is split between your style and Defence |
| **Queueing** | on (default), off | an ability pressed during the global cooldown fires when it ends, or is ignored |
| **Revolution** | off, builders, everything | the bar fires abilities by itself when you press nothing |
| **Run** | on, off | remembered between sessions |
| **Fishing controls** | steer (default), reel only | how you fight a trophy fish |
| **Interface** | lock, scale, reset, layout presets | the windows |
