# Dreaming

*Draft (2026-11-03). From `docs/skills.md` 7, Dreaming, and `docs/lore.md` II. Designed; it arrives
with the first way into the Dreaming.*

## Summary

The skill closest to the story: pulling fragments out of memory orbs in the Dreaming, where places
stand as people remember them. The dreamer notices who takes what.

## Goals

- A skill that is also a way to read the world's secrets ([pillar 2](../../1-overview/pillars.md)).
- The top catalysts for rites and medicine.

## Ties to the setting

Moved places still stand in their old locations in the Dreaming, so old maps are true there. Orbs of
the town, of moved places, of what the last revision took out. The nightmare is fought in the deepest.

## How it is trained

An orb opens a small memory scene. Threads drift through it; start pulling one, which takes a few
ticks and can fail by level. Now and then the memory notices you: an echo walks your way, and you
step off its path or the pull breaks. Active by nature; slow orbs can be semi-AFK.

## The ladder

Deeper orbs by level. Yields: dream fragments by tier (catalysts for rites from tier 7, rare
Medicine secondaries), lucid draught ingredients, and **vignettes**, short scenes of the world's
memory kept in the journal; a full set of an orb's vignettes is a collection.

## Ties to other skills

Occultism, Medicine; shortcuts through places that remember being open.
