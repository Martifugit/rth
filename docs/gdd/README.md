# Welcome

This is the game design document of R'th: what the game should be, one page per thing, grown from
[the game page](rth-overview.md) outward by following links.

Read in this order:

1. [The Charter](charter.md): the ten rules every page follows.
2. [How the GDD Works](how-the-gdd-works.md): pages, types, components, and who writes what.
3. [Writing a Page](writing.md): writing like a wiki, linking out instead of explaining in place.
4. [Using Codex](using-codex.md): making pages, links, templates and comments in the app.
5. [Workflow](workflow.md): when to edit and when to comment, decisions, and naming.

Then start at [the game page](rth-overview.md) and follow the links.

To see what has been decided and when, check the [Decisions log](decisions/decisions-log.md).
