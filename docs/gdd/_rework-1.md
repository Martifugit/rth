The GDD Golden Rules
Ten rules to live and die by when writing the game design document.
Read these first. Then read How the GDD Works for how pages, types and components fit together.
I. The GDD leads, the game follows
Write what the game should be. Words come first; code and numbers come later. If they disagree, either fix the game or change the page on purpose, never by accident.
II. Grow from the top, by following links
The game page leads to regions. Regions lead to the things in them. Each thing leads to whatever it touches. Never start in the middle, and never plan the whole web ahead of time. Write a page, link what it mentions, then follow the links.
III. One page, one thing
A page is about one thing you can name: Goblin, Mossy Hollow, The Missing Cart. If the title needs an "and", split it. If two pages are always read together, merge them.
IV. Say it once, link it everywhere
Every fact has exactly one home. Everywhere else links to it instead of repeating it. A copied fact is a future contradiction.
V. Whoever owns the relationship writes it down
The region says what lives there. The quest says what the NPC does in it. The NPC page just points back. When you don't know where something goes, ask whose page it would be missing from.
VI. A stub beats a blank
Two sentences (what it is, where it is, how you interact with it) are a complete page for now. A link to a page that doesn't exist yet isn't a mistake. It's a to-do.
VII. Why before what
Start every page with its intent: why it exists and what the player should feel. Rules come next, numbers last. Numbers change; the why survives.
VIII. Only as deep as the next thing you'll build
Detail is a cost, not a virtue. Go deeper when you're about to build it or argue about it, not before. Detailed plans for untested ideas get thrown away.
IX. Same kind of page, same headings
Every NPC that runs a shop has a Shop heading in the same place. Use the template, and only add headings that apply. A tired goblin with no stats is not an exception, just a shorter page.
X. If it's not on the page, it didn't happen
Decisions go on the page, not in Discord's memory. Unsolved things go under Open questions. Cut ideas are marked Cut, with a line on why, rather than deleted, so nobody suggests them again in six months.
When in doubt: start smaller, link more, write the why.
