# Appendix: glossary

The words this document uses with one meaning. Added to as pages are written.

| Term | Meaning |
| --- | --- |
| **Tile** | One step of the world. Walking is a tile a tick, running two. |
| **Tick** | 600 ms, the step everything advances by. |
| **Area** | The unit the world is designed in: a stretch of land with one identity, a few regions across. |
| **Region** | A square of the world, usually 96 by 96 tiles, built as one piece. |
| **Place** | A named spot in an area: a town, a farm, a landmark, a dungeon. |
| **Site** | A spot kept free in the layout for content not designed yet. |
| **Tier** | A step on a skill's ladder of resources and gear, every ten levels. |
| **Stage** | Rough account progress: early (tiers 1-3), mid (4-6), late (7-10). Used to check spread, never a gate. |
| **Seed** | An area's, dungeon's or quest's short first design (Ryan). |
| **Paper design** | Its full design, written when it is next to be built (Ryan). |
| **Sealed** | True in the world, but not decided beyond its constraints and not told to the player. |
| **Revision** | One of the ages in which the world is remade: things added, moved and taken out. |
| **The spoil** (p-spoil) | Where everything taken out of the world goes. |
| **Revised** | Partly remade by the present revision (a revised fish). |
| **Node** | Something gathered from: a rock, a tree, a fishing spot, a herb patch, a fount. |
| **Station** | Something made at: a furnace, an anvil, a range, a bench, a vat. |
| **Builder, spender, ultimate** | Abilities that build phlegm, spend some, and spend a full bar. |
| **Overhead** | A hymn that halves one style's damage, or returns blood; one at a time. |
| **Fount** | A monument's node: it cuts you and takes your blood. |
| **Pledges** | Religion's points, spent on scriptures. |
| **Scripture** | What a verse burns. |
| **Carcass** | What a creature drops; butchered for everything else. |
| **Obol** | A coin carried for Pennick's fee. |
| **AFK** | Away from keyboard: done with little attention. |
| **p-name** | A placeholder name, never shown to players. |
