# Defence

## Intent

Defence is how a fighter stays up. Each level adds to the [blood](../systems/blood.md) a player can lose, and it makes [armor](../systems/armor.md) worth wearing. It trains in every [combat style](../systems/combat-style.md), so a [melee](melee.md), [ranged](ranged.md) or [occultism](occultism.md) fighter all build it as they go.
